🔍 内容审查（只混淆色情图片）

开启（默认）：所有图片都会过一遍检测，只有得分 ≥ 阈值的才混淆；检测失败时保守处理（仍然混淆）。
关闭：所有图片都混淆（最保守，一张不漏）。
⚠️ 本地检测是肤色启发式而不是模型，对插画 / 泳装 / 特写会漏判—— 漏判的那张会以原图发出去。介意的话就关掉这个开关。
只混淆色情图片
开（默认）= 景物截图等普通图直接原图发送，不影响正常交流
审查方式
本地 = 零网络零隐私风险（肤色面积+集中度+平滑度启发式）
判定阈值
越低越容易被当成色情图而混淆（推荐 0.6~0.75）
⚠️ 隐私警告：选「远端 API」意味着把图片（已缩到 512px）发给第三方服务器， 这与本插件「防图片外泄」的初衷相矛盾。如果图本身就是不想让人看到的，请用本地启发式。
API 供应商
generic = 任意 POST base64 、回 JSON 带分数的接口
API 地址
generic 模式必填，例：https://你的服务/nsfw
API 用户/ID
Sightengine 的 api_user；generic 不用填
API 密钥
generic 会作为 Bearer token 发送
